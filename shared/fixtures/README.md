# Фикстуры

Не меняйте эти файлы — на них завязан acceptance-чекер.

| Файл | Содержимое |
|---|---|
| `sample.csv` | 12 валидных записей, 3 модуля (`can`, `io`, `power`), 5 уровней |
| `malformed.csv` | 3 валидные + 3 некорректные записи (плохая дата, плохой уровень, мало полей) |
| `empty.csv` | только заголовок |
| `quoting.csv` | проверка RFC 4180: запятая и удвоенные кавычки внутри поля |

## Ожидаемые результаты по `sample.csv`

- всего: 12
- по уровням: `TRACE=1 DEBUG=2 INFO=4 WARN=2 ERROR=3`
- по модулям: `io=5 can=4 power=3`
- диапазон `09:00:00..10:30:00`: 5 записей
- `--min-level WARN`: 5 записей
- `--module can`: 4 записи
- `09:00 + ERROR + can`: 1 запись

## Ожидаемые результаты по `malformed.csv`

- валидных: 3 (`ok`, `fine`, `Comm lost, retrying`)
- некорректных: 3
- `skipped: 3`

## Ожидаемые результаты по `quoting.csv`

- 2 записи
- сообщение первой: `Comm "lost", retrying`
